You are an expert senior full-stack product engineer, UX designer, AI systems architect, and hackathon prototype builder.

Build a complete end-to-end working prototype called:

MRPL CONFIDENTIAL INDUSTRIAL WORKCELL

Project:
SIH26117 — Sovereign On-Premise Agentic AI Workbench using Open-Weight Multimodal LLMs for Confidential Industrial Work

IMPORTANT:
This is a hackathon prototype, not a production enterprise system.

The goal is NOT to implement every enterprise component from the architecture document.

The goal is to build ONE polished, convincing, fully navigable end-to-end Workcell experience that demonstrates the core product idea:

Employee creates an industrial task
→ Workcell is initialized
→ identity, role, scope and evidence are validated
→ authorized documents are admitted
→ system creates a bounded execution workflow
→ employee starts the workflow
→ local-AI-style agent performs the task using permitted tools/models
→ progress is continuously shown
→ if an important exception/risk is detected, execution pauses
→ human reviews and approves/rejects
→ workflow resumes
→ result is independently verified
→ final work package is generated
→ approval/release is shown
→ complete process remains auditable

The UI must be extremely clean, professional, simple and easy for an industrial employee to understand.

Do NOT create a giant dashboard containing every backend technology.

Do NOT expose unnecessary implementation details such as Neo4j, Qdrant, OPA, PostgreSQL internals, agent framework internals, model infrastructure, etc. as primary UI features.

The user should understand the product without understanding the architecture.

==================================================

The central abstraction is the WORKCELL.

A Workcell is a server-controlled execution environment for ONE specific industrial task.

It binds together:

- User identity
- User role
- Task
- Asset/project scope
- Classification
- Authorized evidence
- Evidence versions
- Permitted AI capabilities
- Permitted tools
- Bounded workflow
- Exceptions

2. What information am I providing?
3. Is the system allowed to use it?

5. Is there a problem?
6. Do I need to make a decision?
7. Is the result verified?

WHAT IS HAPPENING
WHY IT IS HAPPENING

WHETHER THE USER NEEDS TO ACT
